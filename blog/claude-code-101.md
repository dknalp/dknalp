# if you use Claude Code, take this free course first

ok so I just found out Anthropic has a free course called Claude Code 101 and honestly I wish I knew about it way earlier.

if you are just starting to code, doing vibe coding, or already using Claude Code but feel like you are kind of just winging it, take this course. it takes like 20 minutes. seriously.

it covers stuff like how Claude Code actually thinks (the agentic loop), how to write prompts that actually work, the Explore > Plan > Code > Commit workflow, how to manage context so it doesn't go off the rails, and what tools like CLAUDE.md, MCP, and Skills even do.

before I took it I was just typing stuff and hoping for the best. after it I actually understood why some sessions go great and others just spiral.

and the best part, it's completely free and you get an official Anthropic certificate when you finish. takes like 20 minutes, no coding experience required to understand it.

https://anthropic.skilljar.com/claude-code-101

if you are already a senior dev who lives in the terminal this might feel basic. but if you are anywhere between "I just installed Claude Code" and "I sort of know what I'm doing", this is the fastest way to fill in the gaps.
